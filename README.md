# 任务矩阵 TASK//MATRIX

常驻 Windows 任务栏的四象限（艾森豪威尔矩阵）计划工具，电子工业风。

## 下载哪个

| 文件 | 说明 |
|---|---|
| `TaskMatrix-Setup-1.0.0.exe` | 安装版（推荐）。可选安装位置，自动创建桌面和开始菜单快捷方式，可在系统设置里卸载 |
| `TaskMatrix-1.0.0-免安装版.zip` | 免安装版。解压到任意文件夹，运行里面的 `任务矩阵.exe` 即可；不想用了直接删文件夹 |

两个版本的任务数据是共用的，存放在 `%APPDATA%\任务矩阵\data.json`，换版本或重装都不会丢。

> 程序没有做代码签名，第一次运行时 Windows SmartScreen 可能提示"已保护你的电脑"，点 **更多信息 → 仍要运行** 即可。

## 系统要求

- Windows 11 x64（Windows 10 大概率也能用，未专门测试）
- 任务栏在上 / 下 / 左 / 右都支持，包括 StartAllBack 等第三方任务栏

## 怎么用

- **呼出面板**：点托盘的四色方块图标，或按 `Alt+Shift+Q`
- **添加任务**：输入后回车；`Tab` / `Ctrl+1~4` 选象限
- **完成任务**：点任务左边的方块（有音效、粒子和经验值反馈，10 秒内连续完成有连击）
- **编辑 / 换象限**：双击文字编辑；拖到别的象限
- **任务栏小组件**：任务直接显示在任务栏空白处，可以勾选完成；右键任务卡片可以完成、编辑、换象限、删除
  - 经典任务栏（StartAllBack / ExplorerPatcher）下会自动避开应用图标和托盘，图标变多时自动缩窄
  - 原版 Win11 任务栏下为紧凑模式，可拖动到空白处
  - 全屏游戏 / 视频 / 演示时自动隐藏
- **右键托盘图标**：小组件开关、钉住面板、音效、开机自启、主题与皮肤、退出

## 主题与皮肤

- **主题**（配色）：钢铁灰、冷却液、警戒黄、铝板
- **皮肤**（UI 风格）：工业、极简、战术 HUD

两者可任意组合，在面板右上角 `SKN` 或托盘右键菜单里切换。

## 从源码构建

```bash
npm install
npm start          # 开发运行
npm run dist       # 打包到 dist/
```

自定义主题/皮肤：见 `renderer/themes.js` 顶部注释。
